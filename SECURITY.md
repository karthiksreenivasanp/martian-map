# Security Policy

## Scope
Martian Map is a static client-side web application hosted on GitHub Pages. It has no backend servers, user accounts, databases, or privileged credentials.

## Reporting a Vulnerability
If you discover a security vulnerability or potential exposure:
1. Please do not open a public GitHub issue.
2. Report the issue privately to the repository maintainer via GitHub Security Advisories at https://github.com/karthiksreenivasanp/martian-map/security/advisories/new.
3. Provide a description of the issue, affected files, and steps to reproduce.

Security reports are reviewed promptly and addressed in accordance with coordinated disclosure practices.
